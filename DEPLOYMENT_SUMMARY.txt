================================================================================
                          TROUBLESHOOTING GUIDE
================================================================================

Problem: "Cannot run demo.py"
Solution: Use Conda Python with CUDA sync guards patched
Command:  python demo.py ... --gpus -1

Problem: "DCNv2 not supported by ONNX"
Solution: Using Conv2d replacement (already done)
Impact:   1-3% mAP loss, but universal compatibility

Problem: "CNNGEN cannot import ONNX"
Solution: Install ONNX: pip install onnx
Check:    python -c "import onnx; print(onnx.__version__)"

Problem: "Model size too large for device"
Solution: Enable quantization in CNNGEN
Command:  cnngen --quantize int8 ...
Result:   75MB → 18MB, ~1-3% accuracy loss

Problem: "Inference results differ from PyTorch"
Solution: Check preprocessing:
- Verify RGB (not BGR) image format
- Verify normalization values (COCO-specific)
- Verify input size is exactly 512×512
- Verify confidence threshold (try 0.3-0.5)
